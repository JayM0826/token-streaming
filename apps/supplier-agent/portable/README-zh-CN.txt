共算云供应客户端（Windows x64 便携版）

1. 解压整个文件夹，不要只单独复制启动脚本。
2. 双击 start-agent.cmd。
3. 默认浏览器会打开本地供应控制中心。
4. 首次配置 Provider、精确模型、共算云平台地址、稳定公网 HTTPS 节点地址、API Key 和本地加密口令。
5. 客户端会自动生成网关令牌；只把“平台接入资料”中的网关地址和网关令牌提交到共算云。
6. 文件任务默认支持到 256 MiB，并由客户端主动连接平台领取；界面会显示任务编号、分段和已处理字节。无需为文件任务开放新端口。

安全要求：
- 不要填写 ChatGPT/Codex 密码、Cookie 或 OAuth 登录态。
- 不要把本地管理端口 8790 暴露到公网或局域网。
- 本地管理会话只使用 HttpOnly Cookie；网关令牌每次查看都要重新输入本地口令，并在 60 秒后自动隐藏。
- 公网反向代理或命名隧道只转发节点端口（默认 8789）。
- 当前文件任务只处理 UTF-8 文本、Markdown、CSV/TSV、JSON/NDJSON 和 XML；不解压、不执行文件，也不访问文件中的链接。
- 文件任务断点只保存加密中间摘要，完成后自动删除；原始客户文件不写入普通本地目录。
- 供应节点和上游 Provider 在执行时仍会看到客户明文；这不是“供应方不可见”的机密计算环境。
- Provider API Key 只在本机加密保存，绝不能提交给平台。
- 忘记本地加密口令无法恢复，需要轮换 Provider Key 和网关令牌。

doctor.cmd 可以在不解锁凭据的情况下检查本地配置。
